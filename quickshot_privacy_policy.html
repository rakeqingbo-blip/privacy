QuickShot Privacy Policy

Effective Date: November 26, 2026 · Publisher: rake
Privacy First: QuickShot processes screenshots and screen recordings locally on your device. We do not operate a backend server, display ads, or collect browsing history.

1. Data We Do Not Collect

QuickShot ("the Extension") does not collect, store, track, or sell your personal information, browsing history, screenshots, screen recordings, or usage analytics.

2. Local Browser Storage

Your preferences—including interface language, optional watermark text, and your own AI API settings (Base URL, model name, and API Key)—are stored strictly inside your browser's local storage (chrome.storage.local). Temporary preview images passed between extension tabs are stored in session memory (chrome.storage.session) and cleared automatically.

3. User-Initiated AI Vision Requests (BYOK)

AI Vision features (OCR, translation, summarization, and Markdown conversion) are strictly opt-in. Only when you explicitly click an AI Vision action does the Extension send the currently selected screenshot directly from your browser to the third-party AI API endpoint you configured (such as DeepSeek, OpenAI, Google Gemini, SiliconFlow, DashScope, or a custom OpenAI-compatible URL). Those third-party services are governed by their own privacy policies.

4. Permissions Explained

  • activeTab & scripting: Capture the active tab and inject the screenshot, annotation, scrollshot, and recording overlay only when you trigger the extension.
  • downloads & clipboardWrite: Save captured PNG/WebM files locally or copy images and OCR text to your clipboard upon request.
  • storage: Store local user preferences and temporary preview images.
  • host_permissions / optional_host_permissions: Used solely to connect to your chosen AI Vision API endpoint when you invoke AI analysis.

5. Chrome Web Store User Data Policy Compliance

The use of information received from Google APIs or browser interfaces adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.

6. Contact

If you have any questions about this Privacy Policy, please contact rake at rake@live.cn.

隐私优先：QuickShot 的截图、长截图与录屏均在您的本地浏览器内完成处理。我们不运营后端服务器，不含广告，也不收集浏览历史。

1. 我们不收集的数据

QuickShot（以下简称“本扩展”）不会收集、存储、追踪或出售您的个人身份信息、浏览记录、截图、录屏文件或使用行为统计数据。

2. 浏览器本地存储

您的偏好设置（包括界面语言、自定义水印文案以及您自行配置的 AI 接口地址、模型名称与 API Key）仅存储在您的浏览器本地（chrome.storage.local）中。用于标签页之间传递预览图的临时图像仅存放在会话存储（chrome.storage.session）并在使用后自动清理。

3. 用户主动触发的 AI 视觉识图（BYOK）

AI 识图功能（文字提取、翻译、总结与转 Markdown）完全由用户自主选择触发。仅在您主动点击相关 AI 按钮时，本扩展才会将当前选中的截图直接从浏览器发送至您自行配置的第三方大模型接口（如 DeepSeek、OpenAI、Google Gemini、硅基流动、阿里云百炼或自定义 OpenAI 兼容接口）。第三方模型服务的数据处理适用其各自的隐私政策。

4. 权限用途说明

  • activeTab 与 scripting：仅在您主动点击扩展图标或快捷键时截取当前标签页并注入截图、标注、长截图与录屏界面。
  • downloads 与 clipboardWrite：在您点击保存或复制时，将图片/视频保存到本地或复制结果到剪贴板。
  • storage：在本地保存用户设置及临时预览图。
  • host_permissions / optional_host_permissions：仅在您主动发起 AI 识图时请求所配置的视觉模型 API 域名。

5. 合规声明

本扩展对浏览器接口信息的处理严格遵守《Chrome Web Store 用户数据政策》（包含 Limited Use 限制性使用要求）。

6. 联系方式

如对本隐私政策有任何疑问，请发送邮件至 rake@live.cn 联系发布者 rake。
